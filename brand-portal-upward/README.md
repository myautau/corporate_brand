# Движение букв вверх

Отдельная вариация `brand-portal-depth`; предыдущие версии не изменены.

Плотность потока уменьшена примерно на 10% относительно предыдущих 65 символов: теперь 59 (50 исходных и 9 дополнительных). Дополнительные символы берутся из исходного набора и размещаются в свободных промежутках; размеры, прозрачность, блюр и скорости не меняются.

Повторяющиеся формы распознаются независимо от размера и экспорта. На соседних траекториях используются разные формы; одинаковые разнесены минимум на 180 пикселей макета по горизонтали, поэтому разная скорость и зацикливание не сближают их. Позиции, количество и настройки глубины сохранены; при замене формы сохраняются её пропорции и общий масштаб.

http://127.0.0.1:5179/corporate_brand_upward/

Символы непрерывно поднимаются вверх. Скорость ближнего плана — 48, среднего — 36,3, дальнего — 27,72 пикселя макета в секунду. Переход в начало цикла происходит за пределами экрана, с запасом для размера букв и размытия. Шрифт, ассеты и компоновка перенесены из предыдущего варианта. Подсветка под курсором учитывает текущее положение движущейся буквы.

Поток букв запускается сразу при открытии, без кнопки «Плей/пауза». Системное уменьшение движения отключает параллакс, но не поток букв. В скрытой вкладке движение приостанавливается. Аналитики нет. Навигация и PDF остаются демонстрационными.

`npm run dev` — запуск; `npm run build` — сборка; `npm test` — проверки движения и бесшовного цикла.

Под первым экраном добавлен белый блок материалов из версии depth: пять карточек с исходной графикой. Прямая ссылка: `/corporate_brand_upward/#materials`. Блюр карточки книги — 16 px на отдельном фоновом слое; содержимое карточки не размывается.
